📡 Message & Data Flow

1
User types a question → app.py
st.chat_input captures text · stored in st.session_state["messages"] · conversation history maintained across turns
2
app.py → agent.chat(query, history)
Passes user message + full conversation history to FinancialLiteracyAgent · returns (reply, updated_history)
3
agent.py → ModelInference.chat(messages, tools=TOOLS_SCHEMA)
Sends [system prompt + history + user message] + 9 tool schemas to ibm/granite-4-h-small via watsonx.ai REST API · model decides whether to call tools or answer directly
4
finish_reason = "tool_calls" → dispatch_tool(name, arguments_json)
tools.py executes the matching Python function (math-based, no external API) · returns structured JSON result · appended as role:"tool" messages · loop repeats
5
finish_reason = "stop" → final reply returned to UI
Granite composes a plain-English answer grounded in tool results · reply displayed in chat bubble · history updated for next turn
Design Principles
🔐
Credentials Never Exposed
API key and Project ID stored in config.py only. Never rendered in the UI. .env.example provided for local use. .gitignore blocks .env.
🧮
Calculations Always Tool-Grounded
Model never estimates numbers. All financial calculations go through deterministic Python math functions. Results are exact and verifiable.
🌐
Multilingual by Design
Granite 4H Small supports 12 languages natively. System prompt instructs the model to respond in Hindi, Tamil, Telugu, Bengali, Marathi, Gujarati, Kannada on request.
